# proerd_convites

Gerador de convites de formatura do PROERD (página estática, um único `index.html`).

## Deploy (Dokploy)
Build Type **Static** (ou **Dockerfile**), porta **80**.

## Logos
- `logos/originais/` — arquivos exatamente como foram recebidos (não alterar).
- `logos/processados/` — versões sem fundo e recortadas, usadas no gerador (já embutidas no `index.html`).

Logos fixos na lista: Apucarana, Arapongas, Cambira, Jandaia do Sul, Kaloré e Marumbi.
